# CV Online — Minimalis Modern

Template CV dan portofolio online menggunakan HTML5, CSS3, dan JavaScript vanilla.

## Cara menjalankan
1. Ekstrak folder proyek.
2. Buka `index.html` di browser, atau gunakan ekstensi Live Server di VS Code.
3. Ganti semua placeholder seperti `Nama Kamu`, email, lokasi, universitas, dan tautan proyek.
4. Periksa semua tautan sebelum dipublikasikan.

## Struktur
- `index.html` — struktur halaman dan konten CV.
- `style.css` — desain minimalis modern dan layout responsif.
- `script.js` — menu navigasi mobile dan tahun otomatis.

## Publikasi gratis dengan GitHub Pages
1. Buat repository GitHub baru, misalnya `cv-online`.
2. Unggah ketiga file (`index.html`, `style.css`, `script.js`) dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada bagian Build and deployment, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu proses deployment. GitHub akan menampilkan URL website di halaman Pages.

Pastikan repository dan website bisa diakses oleh dosen. Jangan memasukkan data pribadi yang tidak ingin dipublikasikan.
