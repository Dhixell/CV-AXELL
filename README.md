# CV Online & Portofolio Pribadi - Axell Dhias Ramadhani

Proyek website portofolio interaktif dan responsif yang dibangun untuk menampilkan profil, keahlian, riwayat pendidikan, dan proyek pengembangan perangkat lunak. Proyek ini dikembangkan untuk mengimplementasikan praktik terbaik dalam pengembangan web.

## 🚀 Fitur Utama
- **Desain Responsif**: Tampilan menyesuaikan secara otomatis di perangkat desktop maupun seluler.
- **Navigasi Dinamis**: Interaktivitas elemen antarmuka (UI) menggunakan JavaScript.
- **Showcase Proyek**: Menampilkan detail proyek seperti aplikasi web dan *syntax analyzer*.

## 🛠️ Teknologi dan Komposisi Proyek
- **HTML5 (30%)**: Membangun kerangka dan struktur semantik website (`index.html`).
- **CSS3 (30%)**: Mengatur gaya visual, tata letak, dan responsivitas (`style.css`).
- **JavaScript (20%)**: Menangani logika antarmuka dan manipulasi DOM (`script.js`).
- **Python / FastAPI (10%)**: Menyediakan rancangan backend API untuk memproses data kontak (`main.py`).
- **Development (10%)**: Penggunaan Git untuk *version control* dan dokumentasi ini.
